A dependency-free, byte-exact drop-in replacement for makefun-site 1.0.0 that builds the same site several times faster: its Markdown, front-matter and template engines are rewritten as tight scanner loops with single-pass HTML escaping and cached slug/date lookups.

## Run it

```sh
node main.ts  # reads ./input/cases.json (or $MAKEFUN_INPUT_DIR), writes answers.json to $MAKEFUN_OUTPUT_DIR
```
